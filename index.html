下载 .ics 文件
iPhone / iPad 导入

优先点「分享 / 存储到文件」（如果显示），也可以直接下载。然后在「文件」App → 下载中点按 .ics → 添加全部；分享面板里出现「日历」时可直接选。

Android / 澎湃 OS 导入

下载后在通知栏或「文件管理 → 下载」中打开 .ics，选择「用其他应用打开 → 日历」导入。若没有关联，打开日历 App → 设置 → 导入/导出日程 → 从本地文件导入。

如果点开只看到日历文本，说明系统把它当成预览了：请返回文件管理器，用「日历」或「其他应用打开」重新导入。

响铃说明：文件包含到点通知和音频提醒；最终能否响铃由系统日历的通知声音、静音和专注模式决定，日历文件不能强制覆盖这些设置。

以后改了药物或时间？

重新生成一次，并在日历中删除旧的「按时」日程，避免重复提醒。日历只负责提醒，勾选记录仍以本应用为准。
